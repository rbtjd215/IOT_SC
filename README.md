# IoT 보안 프로젝트 발표

ipTIME N704-V3를 대상으로 UART 진단 접근, 개방형 Wi-Fi의 전송 내용 보호,
WPS 비활성화 설정과 물리 버튼 동작을 분석하는 발표입니다.

**[웹에서 슬라이드 보기](https://rbtjd215.github.io/IOT_SC/)**

**[발표 PDF 보기·다운로드](https://rbtjd215.github.io/IOT_SC/slides.pdf)**

## 발표 조작

- 방향키 또는 화면 아래 이전·다음 버튼으로 이동합니다.
- `O`: 전체 페이지 개요
- `F`: 전체 화면
- `M`: 등장 모션 정지·재생
- 주소 끝에 `#8`처럼 페이지 번호를 붙이면 해당 페이지를 바로 엽니다.

전체 20페이지입니다. 실습 전 예상 결과와 공개 분석 근거를 구분해 작성했습니다.
설명 사진은 생성한 개념 이미지입니다.

## 구성

- `index.html`: 발표 HTML
- `assets/`: 발표에 사용하는 스타일·스크립트·폰트·이미지
- `slides.pdf`: 공개 발표 PDF

GitHub Pages는 `main` 브랜치의 루트 폴더를 게시합니다.
발표 내용의 수정은 `index.html`에 반영합니다.

폰트는 Pretendard를 사용합니다. [폰트 라이선스](assets/Pretendard-LICENSE.txt)를 포함했습니다.
공개 근거 문서는 각 슬라이드 하단의 외부 링크에서 확인할 수 있습니다.
