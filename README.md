# 2팀 IoT 보안 프로젝트 발표

ipTIME N704-V3를 대상으로 UART 진단 접근, 개방형 Wi-Fi의 전송 내용 보호,
WPS 비활성화 설정과 물리 버튼 동작을 분석하는 발표입니다.

**[웹에서 슬라이드 보기](https://rbtjd215.github.io/IOT_SC/)**

**[발표 PDF 보기·다운로드](https://rbtjd215.github.io/IOT_SC/slides.pdf)**

## 발표 조작

- 방향키 또는 화면 아래 이전·다음 버튼으로 이동합니다.
- `O`: 전체 페이지 개요
- `F`: 전체 화면
- `M`: 등장 모션 정지·재생
- 주소 끝에 `#8`처럼 페이지 번호를 붙이면 해당 페이지를 바로 엽니다.

전체 21페이지입니다. 실습 전 예상 결과와 공개 분석 근거를 구분해 작성했습니다.
시나리오 설명 사진은 생성한 개념 이미지이며, 4페이지 영상 썸네일은 KBS 공식 영상의 이미지입니다.

## 최근 반영 내용

- 4페이지: 2026년 공유기 DNS 변조 사례와 클릭 가능한 KBS 관련 시연 영상
- 8페이지: 단계별 공격 경로와 WPS 등록 시작·실제 가입 구분
- 9페이지: STRIDE 여섯 분류와 시나리오별 적용
- 13페이지: 기존 개념 사진에서 별도 무선 수신기 강조
- 16페이지: 증거 설명 위치 정렬
- 20페이지: 2팀 역할 분담
